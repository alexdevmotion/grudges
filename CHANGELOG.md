# Changelog

## 0.2.0a1 — 2026-10-21

- Subscription replay through installed Codex and Claude CLIs, with native login and no API fallback.
- Sequential trusted local workspaces, baseline/reference controls, and offline Docker verification.
- Frozen rules comparisons, durable attempt receipts, and subscription-aware cost labels.
- Explicit tool-profile and host-isolation limitations; errors stop further allowance use.

## 0.1.0a1 — 2026-10-20

- Local failure capture, request selection and interactive Harbor task authoring.
- Bundled starter and intent packs, with fairness notes and reference controls.
- Frozen replay inputs, API-key-only native harness replay, and optional rules comparison.
- Attempt-level HTML cards with missing/error accounting and partial cost labels.
- Managed installation that preserves unrelated hooks and modified skills.

This is a workflow alpha, not a calibrated public model ranking. Private rules-trial headline scores were withdrawn after fixture and rule-contract defects were found; those receipts are not shipped.
